## Main Recruiter-Facing Job Description

The primary source is:

`Role.enhancedJd`

This is stored as one Markdown/text field and parsed into sections based on headings.

| Dashboard section          | Source within `Role.enhancedJd`                      |
| ----------------------------| ------------------------------------------------------|
| About the Company          | `About Company` / `About [Company Name]`             |
| About the Role             | `About the Role`                                     |
| Responsibilities           | `Responsibilities`                                   |
| Required Skills            | `Required Skills` / `Requirements`                   |
| Bonus Skills               | `Bonus Skills` / `Preferred Skills` / `Nice to Have` |
| Ideal Background           | `Ideal Background`                                   |
| Example Profiles           | `Example Candidates` / `Example Profiles`            |
| Green Flags                | `Green Flags`                                        |
| Red Flags                  | `Red Flags`                                          |
| Interview Process          | `Interview Process` / `Hiring Process`               |
| Submission Requirements    | `Submission Requirements`                            |
| Benefits / Other logistics | `Logistical Info`                                    |

## Target Companies

The **Target Companies** section is pulled from:

`Role.detailEnrichment → targetCompanies`

Each entry has this structure:

```json
{
  "name": "Celonis",
  "reason": "Why this company is a relevant talent source",
  "industry": "Enterprise software and process intelligence"
}
```

The displayed company name is:

`Role.detailEnrichment.targetCompanies[].name`
